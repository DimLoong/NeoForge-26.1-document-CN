# 导读 {#primers}

本仓库中的导读旨在概览性、非详尽地介绍如何在两个 Minecraft 版本之间迁移 Mod。每个小节对应导读所面向的版本。

1.12-1.17 版本的导读将原版改动与 Forge 改动合并为一体。其余所有导读则在主体部分记录原版改动，Mod 加载器的改动放在以其名称命名的子小节中。

这些导读的作者为：
* 1.12-1.15 由 [@williewillus](https://github.com/williewillus) 撰写
* 1.16-1.17 由 [@50ap5ud5](https://github.com/50ap5ud5) 撰写
* 其余所有版本由 [@ChampionAsh5357](https://github.com/ChampionAsh5357) 撰写
